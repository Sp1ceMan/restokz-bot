# RestoKZ — Онлайн-бронирование ресторанов в Казахстане (Telegram WebApp)

Полноценная система бронирования столиков в заведениях Казахстана через Telegram Mini App.

## Возможности системы

### 👤 Для гостя:
- Каталог заведений с фильтрацией по городам (**Алматы, Астана, Шымкент**), кухням и поиску.
- Карточки ресторанов: фото, средний чек в **₸ (тенге)**, рейтинг ⭐, адрес, режим работы и кнопка 2GIS.
- Полноценное меню с блюдами, граммовкой и ценами в ₸.
- Интерактивное бронирование стола:
  - Выбор даты и времени визита.
  - Выбор количества персон.
  - Интерактивная схема столов (зеленые — свободны, красные — заняты, синий — выбран).
  - Ввод имени и номера телефона с автоматической маской Казахстана `+7 (7XX) XXX-XX-XX`.
  - Пожелания к брони (детский стул, день рождения, у окна).
- Раздел «Мои бронирования» со статусами в реальном времени.

### 👑 Для ресторана (Хостес / Администратор):
- **Мгновенные Telegram-уведомления** при новой броне с именем гостя, номером телефона (кликабельный `tel:`), временем, столом и пожеланиями.
- Кнопки быстрого подтверждения прямо в чате: `[✅ Подтвердить]` и `[❌ Отклонить]`. При нажатии гостю сразу приходит подтверждение в боте.
- **Панель управления заведения в WebApp** (вкладка «Для ресторана»):
  - Просмотр всех броней по датам (Сегодня, Завтра, Все).
  - Контакты гостей и кнопка «Позвонить».
  - Смена статуса: «Подтверждена», «Отклонена», «Гости пришли».

## Структура проекта

- [database.py](file:///d:/bot/database.py) — База данных SQLite (рестораны, меню, столы, брони).
- [api.py](file:///d:/bot/api.py) — REST API сервер на `aiohttp.web`.
- [bot.py](file:///d:/bot/bot.py) — Telegram-бот на `aiogram 3` с одновременным запуском API сервера.
- [index.html](file:///d:/bot/index.html) — Telegram Mini App SPA интерфейс (Tailwind CSS).
- [test_system.py](file:///d:/bot/test_system.py) — Автотесты логики базы данных и занятости столов.
- [test_api.py](file:///d:/bot/test_api.py) — Автотесты всех эндпоинтов REST API.
